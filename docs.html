Introduction

Thank you for purchasing NovaAI Admin Dashboard. This is a premium, high-fidelity UI kit designed for AI platforms, SaaS admin panels, and data-heavy applications. It features a modern dark aesthetic with glassmorphism touches, fully responsive layout, and clean code.

Feature Highlight: Built with pure HTML5, CSS3, and Vanilla JS for maximum compatibility and zero build-step requirements.

How to Open in Browser

Since this project uses no complex build tools (like Webpack or Vite) for the base version, you can run it directly.

  1. Navigate to the html/ folder.
  2. Double click index.html to open it in your default web browser.
  3. We recommend using VS Code's "Live Server" extension for the best development experience.

Customization Guide

We use CSS Variables (Custom Properties) for global styling. You can change the entire theme by editing the :root variables in assets/css/style.css.

Colors

:root {
    /* Change the primary blue color */
    --primary-blue: #3b82f6; 
    
    /* Change background darkness */
    --bg-body: #0f111a;
}

Fonts

The template uses Plus Jakarta Sans from Google Fonts. To change it:

  1. Import your new font in the <head> section.
  2. Update the --font-main variable in CSS.
