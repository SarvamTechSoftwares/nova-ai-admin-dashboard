I need to generate a Python function that connects to a Redis database and caches a user profile object. Can you also include error handling?

Certainly! Here is a robust Python function using `redis-py` that handles connection errors and serialization:

import redis
import json

def cache_user_profile(user_id, profile_data):
  try:
    r = redis.Redis(host='localhost', port=6379, db=0)
    r.setex(f"user:{user_id}", 3600, json.dumps(profile_data))
    return True
  except redis.ConnectionError as e:
    print(f"Redis Error: {e}")
    return False
