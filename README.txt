Description:
------------
A professional, high-fidelity AI Admin Dashboard UI featuring a modern, dark-themed aesthetic with glassmorphism effects.
Designed for managing AI agents, viewing analytics, and system configuration.

Features:
- Responsive Design
- Glassmorphism UI
- Interactive Charts (Chart.js)
- Data Tables
- Modal Interactions
